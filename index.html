Consejos para tus modelos

Para esculturas patrimoniales, empieza con 70–85% de triángulos y WebP a 80–90%. Inspecciona inscripciones, rostros y bordes después de reducir geometría.

Para platillos WebAR puedes probar 50–70% y texturas de 1024–2048 px. Es posible que Meshopt aumente algunos archivos por sí solo: compara siempre el tamaño final.

Compatibilidad: si activas WebP y Meshopt, el visor debe admitir las extensiones EXT_texture_webp y EXT_meshopt_compression.

Privacidad: los modelos se procesan localmente; no hay subida a servidores. Se necesita Internet la primera vez para descargar las bibliotecas de optimización y el visor 3D.

Compatibilidad: esta primera versión acepta archivos GLB 2.0. Algunos archivos con compresión Draco, texturas KTX2 o extensiones poco frecuentes pueden requerir conversión previa. Trabaja siempre sobre una copia y verifica el GLB de salida.

Independencia: herramienta de respaldo diseñada desde cero con glTF Transform y meshoptimizer, sin dependencia del servicio AR Optimizer original. glTF Transform · Meshoptimizer.
